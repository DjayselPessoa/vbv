# Política de Segurança

A segurança é uma prioridade para o projeto **VSCode Blog Viewer**.  
Mesmo sendo uma extensão simples, seguimos boas práticas para garantir que o código seja seguro e confiável.

## Relatando vulnerabilidades

Se você encontrar uma vulnerabilidade ou comportamento suspeito:

1. **Não abra uma issue pública.**
2. Envie um e-mail para o mantenedor: [djaysel@gmail.com](mailto:djaysel@gmail.com)
3. Inclua detalhes suficientes para reproduzir o problema.
4. Não envie nenhum link.

> O mantenedor analisará o relatório e responderá o mais rápido possível.

## Boas práticas adotadas

- Nenhum dado pessoal do usuário é coletado.
- Nenhuma requisição é feita para serviços externos além do site oficial do VS Code.
- O código evita execução dinâmica de scripts externos.
- Dependências são mantidas atualizadas para reduzir riscos.

## Atualizações

Esta política pode ser revisada conforme o projeto evolui.

Última atualização: **Junho de 2026**

# Security Policy

Security is a priority for the **VSCode Blog Viewer** project.
Even though it is a simple extension, we follow best practices to ensure the code is secure and reliable.

## Reporting vulnerabilities

If you encounter a vulnerability or suspicious behavior:
1. **Do not open a public issue.**
2. Send an email to the maintainer: [djaysel@gmail.com](mailto:djaysel@gmail.com)
3. Include sufficient details to reproduce the issue.
4. Do not send any links.

> The maintainer will review the report and respond as soon as possible.

## Best practices adopted

- No personal user data is collected.
- No requests are made to external services other than the official VS Code website.
- The code avoids the dynamic execution of external scripts.
- Dependencies are kept up to date to reduce risks.

## Updates

This policy may be revised as the project evolves.

Last update: **June 2026**
