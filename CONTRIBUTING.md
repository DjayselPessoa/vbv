# Contribuindo para o projeto

Obrigado por se interessar em contribuir com o **VSCode Blog Viewer**! 💙  
Toda ajuda é bem-vinda! Seja reportando bugs, sugerindo melhorias ou enviando pull requests.

## Como contribuir

1. **Fork** o repositório e crie uma nova branch:
   ```bash
   git checkout -b minha-contribuicao
   ```
2. Faça suas alterações e garanta que o código esteja limpo e funcional:

- Use TypeScript.
- Execute ```npm run compile``` para verificar se tudo compila corretamente.
- Mantenha o estilo de código consistente com o restante do projeto.

3. **Commit** suas mudanças com uma mensagem clara:

    ```
    git commit -m "exemplo: Adiciona melhoria na verificação de novos posts"
    ```
4. **Push** para sua branch e abra um **Pull Request**.

## Diretrizes de código

- Evite dependências desnecessárias.
- Prefira código simples e legível.
- Documente funções públicas com JSDoc.
- Teste antes de enviar.

## Reportando problemas

Se encontrar um bug ou tiver uma sugestão, abra um **issue** descrevendo:

- O comportamento esperado.
- O comportamento atual.
- Passos para reproduzir.
