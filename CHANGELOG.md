# Change Log

All notable changes to the "vbv - VSCode Blog Viewer" extension will be documented in this file.

> The format is based on [Keep a Changelog](https://keepachangelog.com/en/2.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

## [0.0.3] - 27-06-2026

### Added

- Icon display in the status bar guaranteed after adding the activation command.
- README updated - "time of activation"

### Fixed

- Fixing the .vscodeignore file to avoid excluding essential package content and preventing the extension from failing to work.
    

## [0.0.2] - 26-06-2026

### Added

- remove all unnecessary dependencies (dev)
- remove all unnecessary images
- update vscodeignore

## [0.0.1] - 26-06-2026

### Added

- main base of the extension
- fetch of the latest post from VSCode Blog
- save of the post title for update mechanism
- adaptation of content for better display in the webview
- error messages if the fetch fails
- keybindings - icon status bar - command for activation
- full package and node_modules
- README in Portuguese and English
